# HiveUrn

HiveUrn is a real-time data grid platform that enables high-availability, auto-scaling storage clusters with distributed manager nodes.

With HiveUrn, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/HiveUrn.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

HiveUrn is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
